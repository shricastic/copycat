Opening it the first time

Copycat isn't signed with an Apple or Microsoft certificate yet, so your computer asks before opening it.

Mac: drag Copycat to Applications and open it. When macOS says it can't verify the developer, go to System Settings → Privacy & Security and click Open Anyway. You only do this once.

Windows: if SmartScreen says "Windows protected your PC", click More info → Run anyway.
